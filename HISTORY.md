# Spaceadom — the dated history

Kept here so the path from the first idea to today's app is on the record.
Every date below is verifiable from public GitHub metadata or a dated
artefact.

| When | What |
|---|---|
| **May 2026** | The idea: hold **Space**, tap the first letter of an app, and it opens; the same chord again minimises it. Built as an AutoHotkey script with a friend, versions v3.6 → v11. Published as **[SpaceToggle OS](https://github.com/nur-arpon/SpaceToggle-OS)** on 26 May 2026; release **v11.0.0 on 30 May 2026**. Those scripts are still in that repository, unchanged. |
| **June 2026** | v11 hardened (`install-v11.ps1`, 19 June) — the "functional bible" that the rewrite had to match: hold-Space modifier gate, no leaked spaces, rollover protection, launch → focus → minimise cycle, Boss key, guide overlay. |
| **9 July 2026** | First native build: *SpaceToggle OS 1.0.0*, Rust + Tauri — the same behaviour with a settings window a person can edit. |
| **10–11 Aug 2026** | The V13 → V14 rewrite: v11's behaviour, the native app's UI, one codebase. |
| **15 Aug 2026** | Renamed **Spaceadom**; first GitHub release, 1.0.27. |
| **Aug – Sep 2026** | Roughly one release a day: self-update, ARM64 builds, the Space guide ring, themes, touchpad gesture, edge arc. |
| **12 Sep 2026** | The **middle-mouse ring** (1.0.109): the same bindings, raised under the cursor by holding the middle button, aim and release. |
| **17 Sep 2026** | The icon ring anchored on the press point (1.0.112). |
| **21 Sep 2026** | Launch on the cursor's monitor; PowerToys Workspaces as a binding target (1.0.138). |
| **22 Sep 2026** | The ring button is a choice (wheel, Back or Forward, hold or click); Back and Forward become bindable keys; a drawn mouse and a Mouse page; external-monitor brightness over DDC/CI that follows the cursor (1.0.142). |
| **1 Oct 2026** | Visual polish: long notifications keep their shape, round glows (1.0.143). |
| **2 Oct 2026** | Store apps open on the cursor's screen; shortcuts ready the moment you return; fewer false error reports (1.0.145). |
| **6 Oct 2026** | One engine for Windows, Mac and Linux; Mac beta refreshed to 1.0.153 (1.0.154). |
| **6 Oct 2026** | Several apps on one shortcut; little windows (timer, notepad, round picture frame); typing calibration; choose speakers and microphones (1.0.153). Mac and Linux betas. |
| **5 Oct 2026** | Chips fly straight into their notification; the optional Space Boost motion; a Support Spaceadom card in Settings (1.0.151). |
| **4 Oct 2026** | Idle memory cut to about 110 MB; the first-shortcut-after-a-break fix; the portable zip returns (1.0.148). |
| **Sep 2026** | Submitted to the Microsoft Store. |

Radial menus themselves are old — pie menus date from 1988 and there are
other launchers built on them. Spaceadom's starting point was never the
ring; it was the Space chord. The ring is one more door to the same
bindings.

The development log, the bug journal and the source live in a private
repository; this one carries what a user needs — releases, the privacy
policy, the licence and this history.
