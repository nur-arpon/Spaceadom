Questions

Asked first, answered plainly.

Does it get in the way of typing?

No. A tapped Space types a space, exactly as it always has. Only a held Space followed by a letter is a shortcut, and fast typing is always treated as text. You can tune the timing in Settings.

How is it different from PowerToys Run, Raycast or Flow Launcher?

Those are search launchers: you type part of a name and pick from a list. Spaceadom is a chord you learn once. Space+B is your browser, every time, with no typing and no list to read. They work fine side by side.

Is it really free?

Yes. No account, no trial, no ads, and no analytics in the app. Get it from the Microsoft Store, or run winget install spaceadom.

What does it send over the internet?

An optional crash report, which you can switch off, and, outside the Store version, a once-a-day update check. Never what you type or what you've bound. The privacy policy lists everything.

Does it work on Windows on ARM?

Yes. There's a native ARM64 build, and every release is installed and started on real ARM64 hardware before it ships.

Mac or Linux?

Windows only for now. The keyboard hook at its heart is Windows-specific.
